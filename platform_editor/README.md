# 穹顶回响地图编辑器

面向同工作区 `platform_dome` 的浏览器地图编辑器。编辑器使用原生
HTML、JavaScript ES Modules 和 Phaser.js，不需要打包；本地服务使用
`fast-xml-parser` 解析 Tiled JSON 引用的外部 TSX。

## 职责
只负责产出符合 contract 的数据，不实现任何运行时逻辑。
需要新的运行时能力 → 在 contract 里声明，不准在此塞 dome 的代码。
共享协议位于 `platform_contract/`，当前关卡 schema 版本为 `5`。

## 扩展性
新增可编辑对象类型走 registry 注册，禁止在 switch/if 链里加分支。
注册项同时声明放置工厂、默认尺寸、渲染方法、属性面板构建器和稳定 ID 前缀。

## 性能
大场景用增量序列化，禁止每次变更全量 dump。

## 启动

在工作区根目录执行：

```powershell
pnpm --filter platform-dome-map-editor start
```

也可以在本项目目录执行：

```powershell
npm start
```

打开：

```text
http://127.0.0.1:8090
```

编辑器服务默认读取和写入同工作区中的：

```text
../platform_dome/data/levels
```

如果游戏项目位于其他位置，可以在启动前设置 `PLATFORM_DOME_PATH`。

## 当前能力

- 读取游戏现有的 `level-001.json`、`level-002.json`，并依据 `manifest.json` 发现新增关卡。
- 编辑世界尺寸、背景色、镜头参数，以及一个或多个命名出生点。
- 绘制和拖动地形。
- 放置角色、NPC、道具和机关实例。
- 使用统一的“机关”工具放置开关、闸门、入口和出口。
- 入口保存全局 `targetExitId`；角色中点接触入口边缘时传送。可先筛选地图，再选择该地图中的出口。
- 出口是被动传送目标，不主动触发，不保存关卡或通关条件。
- 出生点不占用左侧放置工具，统一在关卡设置中维护，并保存稳定 ID 供后续条件传送引用。
- 在右侧属性面板中精确修改中心坐标、尺寸、颜色及玩法引用。
- 地图对象层级列表、网格吸附、缩放、平移和视图定位。
- 撤销、重做、对象复制、键盘微调和实时数据校验。
- 保存时先校验引用，再原子写入游戏关卡目录，并自动备份旧版本。
- 保存后同步维护 `data/levels/manifest.json`，游戏刷新后即可读取新增地图。
- 另外提供 JSON 导入和导出，便于迁移或版本管理。
- 顶部“素材库”按“关卡背景 / 动画 / 静态贴图”管理工作区素材；“关卡背景”下分为“静态背景”和“Tiled 背景”两类。
- 顶部提供“会话 / 任务 / 物品 / 动画演绎 / 角色”五个独立内容工作区，分别使用 `00 / 01 / 02 / 03 / 04` 作为稳定 ID 前缀。
- 会话模块采用文件资源管理器布局：左侧为最近打开列表，中间为带路径面包屑的目录、文件与会话编辑区。
- 最近会话最多保留 10 项；首次打开的新会话从顶部加入，列表已满时从底部移除一项；再次打开已有会话不会改变顺序，拖拽可手动排序。
- 会话直接在中间文件区打开编辑；进入会话后路径最后一段显示会话 ID，点击上级目录可返回浏览。
- 会话正文使用多轮对话表编辑：标题右侧加号在末尾新增对话行，每行包含角色和说话内容。
- 进入会话时对话行默认全部折叠；序号表示顺序，点击箭头展开编辑，拖拽行可调整顺序，右键行可删除。
- 对话行列表使用独立滚动区域，标题和加号保持固定；新增行后自动滚动到列表底部。
- 会话编辑区不再提供底部删除行，整段会话仍可从文件列表右键删除。
- 会话、任务、物品、动画演绎和角色统一使用文件资源管理器：支持嵌套文件夹、新建、拖拽移动、重命名、删除、复制、剪切、粘贴；删除文件夹会递归删除其中内容和子文件夹。
- 角色模块使用文件资源管理器，并提供可折叠的角色属性面板。
- 每个角色属性默认值为 `0`，包含攻击力；动画可从资源库“动画”分类绑定多个实例。
- 角色拥有唯一共享碰撞体，所有动画帧共用同一归一化矩形；帧设置中切换到“碰撞体”后可拖内部移动、拖边单向缩放、拖角同时调整宽高，使用淡黄色四边形显示。
- 每个动画可在触发键列表之后填写备注，记录用途、触发时机或动作说明。
- 除“其它动画”外，同一角色每种动画类型选中一次后会从添加列表中屏蔽；“其它动画”可重复添加。
- 角色动画支持死亡动画类型，并支持右向默认播放、左向水平镜像、帧速调整、播放预览和攻击帧选择。
- 攻击帧后的“帧设置”弹窗同时维护该帧的攻击范围与短音效：范围支持 `3–12` 个顶点，相邻点可逐段切换直线或曲线，曲线通过二次贝塞尔控制点调整弧度；攻击范围按帧独立保存，只对当前帧生效，不会沿用到其它帧。
- 帧音效从素材库“音效 / 短音效”导入，使用与其他素材导入一致的文件夹浏览器，并保存素材路径、文件夹、音量（0–100%）和是否循环；循环默认关闭，音效在动画播放到该帧时触发。
- 短音效选择窗口在每张音频卡片预览区上半部分提供三角试听按钮，可在不选中素材的情况下直接试听或暂停。
- 角色动画预览播放经过攻击帧时会触发该帧音效；暂停、折叠、删除动画或进入帧设置时停止播放，避免与设置面板试听叠加。
- 帧音效面板支持试听、移除和更换；更换时保留当前音量与循环设置。
- 攻击范围画布使用邻近采样保持硬边缘，支持滚轮以鼠标为中心缩放、拖动平移和适应窗口；范围使用透明浅绿色填充。
- 角色动画的触发键按“向右”和“向左镜像”分开配置，每侧可添加多个键盘或鼠标触发键；当前只保存角色结构，不接入游戏运行时。
- 其他内容模块继续支持新建、删除、名称与说明编辑、撤销与重做；编号按模块流水分配，并由 `idCounters` 保证删除后不复用。
- 每个素材分类可在空白处右键新建文件夹；按住素材拖到文件夹可归档，文件夹支持嵌套，并可拖回上级。
- 文件夹右键支持重命名和删除；删除会二次确认，并递归删除其中的素材、Tiled 素材组和子文件夹。
- 不同文件夹允许素材逻辑重名；导入、拖入或粘贴到同一文件夹遇到重名时，可选择覆盖、重命名或不继续。
- 素材和文件夹右键支持复制、剪切，分类或文件夹空白处右键可粘贴；复制文件夹会连同内部素材和子文件夹一起复制。
- 动画区支持横向 PNG 精灵表，自动按图片高度计算方形帧尺寸与横向帧数，并在卡片和查看器中播放。
- 动画素材右键菜单第一项为“帧速”，使用左侧实时动画预览和右侧控制栏调节 1–60 FPS；调整立即生效，点击“确认”后持久化。
- 右键素材卡片可“查看”或“删除”。查看支持滚轮缩放、拖动平移和双击复位。
- 素材库新增“音效”分类，分为“短音效”和“环境音”；两类都接受 WAV、OGG 和 MP3。音频卡片使用三角播放键；查看器提供大型播放键、进度条拖动、±10 秒、静音和音量控制。
- 地图画布和素材预览的缩放统一使用邻近采样，放大时保持像素硬边缘。
- 地图滚轮缩放以鼠标所在位置为中心，连续缩放时鼠标下的世界坐标保持不动。
- 关卡设置打开背景选择窗口后，先在左侧选择“静态背景”或“Tiled 背景”，再从对应分类中导入素材；两者统一保存到 `world.background`，导入时会把资源同步到游戏项目。
- 关卡设置新增“关卡音乐”：从素材库“音效 / 环境音”的文件夹浏览器导入，窗口与动画帧音效一致，音频卡片上半部分提供三角试听按钮。
- 关卡音乐保存为顶层 `backgroundMusic`，同时记录环境音路径、文件夹、显示名、音量（0–100%）和是否循环（默认循环），并把音频复制到游戏项目的 `assets/audio/ambient`；进入关卡循环播放、离开关卡停止的运行时接入留待后续适配。
- 导入后可在关卡设置中试听音乐、调节音量、切换循环、更换或移除音乐，并查看来源文件夹与路径。
- Tiled 地图通过文件夹导入，地图文件为 `.json` 或 `.tmj`；文件夹内可同时包含外部 `.tsx` 和 tileset 图片。
- 文件夹中存在多个 Tiled 地图时会显示候选列表，可一次选择导入一个或多个地图；素材名称直接使用对应 JSON/TMJ 文件名。
- 与素材库现有 Tiled 地图重名时会询问是否覆盖；确认后原子替换原素材并保留素材 ID，不再自动追加序号。
- Tiled 背景使用 Phaser 原生 Tilemap 渲染，与单图一样随世界尺寸铺满；碰撞按世界比例变换，并以浅绿色只读覆盖层显示。
- Tiled 碰撞来自碰撞对象层、tileset Collision Editor 和瓦片 `collides` 属性；单向平台属性映射到现有 `platform` 碰撞。
- Tiled `tiles[].animation` 会保留到运行时，并在编辑器和游戏内按帧时长播放；同名 tileset 会按 `firstGid` 自动生成唯一名称。
- 所有对象都可拖四角等比缩放、拖四边单轴缩放；导入素材与角色类型不再限制缩放方向。
- 选中对象后，上方显示左右微调箭头，右侧显示上下微调箭头，每次点击固定移动 1 像素。
- 选择工具下点击地图背景即可选中地图，并显示边界手柄；可通过四角和四边调整世界尺寸。
- 地形分为“地面”和“平台”：地面四周碰撞；平台只在角色从上方落下时提供支撑，可从下方跳穿，按下方向键时下落穿越。

## 素材库

素材原始副本保存在编辑器当前工作区；作为关卡背景导入时，选中的
图片或 Tiled 地图素材组会复制到游戏目录并写入关卡引用。

```text
platform_editor/assets/map/backgrounds
platform_editor/assets/map/entities
platform_editor/assets/map/static-textures
platform_editor/assets/map/tiled
platform_editor/assets/audio/sfx
platform_editor/assets/audio/ambient
```

图片支持 `PNG`、`JPG`、`WebP`、`GIF` 和 `SVG`；短音效和环境音都支持 `WAV`、`OGG`、`MP3`，单个文件最大 20 MB。重名文件会自动追加序号，不会覆盖已有素材。

横向 PNG 精灵表规则：

- 帧高等于图片高度；
- 帧宽取图片高度，按方形帧切分；
- 帧数为图片宽度除以图片高度后向下取整；
- 默认帧速为 8 FPS，可在动画素材右键菜单中调整；
- 帧速保存在素材文件旁的 `.meta.json` 元数据文件中。

## 跨项目表现协议

- 当前关卡 `schemaVersion = 5`；旧背景字段由 contract 的迁移函数统一升级。
- 独立内容文档 `schemaVersion = 16`，保存于游戏项目的 `data/content/content.json`；V1–V15 文档会自动迁移。
- 任务编辑器支持任务前置（同任务状态 OR、不同任务 AND）、物品数量完成条件和完成奖励；任务 ID 与物品 ID 分别使用 `01-`、`02-` 固定前缀，物品 ID 在完成条件与奖励中分别去重。
- 物品编辑器支持一级/二级类型、稀有度、堆叠上限、买入/卖出、插图和特殊效果实现。物品名右侧可“导入插图”，从素材库“静态贴图”的文件夹中选择；插图保存素材路径、文件夹 ID 和文件夹路径，选择窗口使用与素材库一致的高卡片预览：图片绝对定位填满预览盒子，再以 `contain` 完整展示，不裁切竖版插图。一级/二级类型与稀有度都可以选“自定义”，确认后写入整个物品模块共享的类型库；同名一级类型会合并。稀有度独立于一级/二级类型。取消“参与买卖”即标记为非买卖品。特殊效果可选“效果描述”或“导入脚本”，脚本导入功能暂未接入，只保存路径与说明。
- 角色动画绑定使用与插图相同的素材库文件夹浏览器，从“动画”分类选择精灵表，并在绑定来源中保留路径与来源文件夹。
- 角色属性包含攻击力；角色 `collisionBody` 使用归一化矩形并跨动画共享，动画绑定的 `note` 保存备注，`attackRanges` 按帧保存攻击范围。
- 关卡音乐使用顶层 `backgroundMusic`，保存环境音的素材路径、游戏内路径、文件夹、MIME、版本、`volume`（0–1）和 `loop`（默认 `true`）；`null` 表示没有背景音乐。
- 动画“帧设置”中的短音效同样使用文件夹浏览器，只列出“音效 / 短音效”；`frameSound` 保存路径、文件夹、`volume` 和 `loop`，音效在到达攻击帧时触发。
- 五类内容 ID 固定为 `00-0001`、`01-0001`、`02-0001`、`03-0001`、`04-0001` 起的格式。
- 图片背景：`world.background = { type: "image", id, path, fileName, fit, revision }`。
- Tiled 背景：`world.background = { type: "tiled", ... }`，保存源 JSON/TMJ、运行时 Tiled JSON、tileset 和地图局部碰撞矩形。
- `id` 指向编辑器素材库中的背景；`path` 是游戏项目内可读取的资源路径。
- 角色实例使用 `scaleX`、`scaleY` 表示水平与垂直缩放；旧 `scale` 仍可作为兼容输入。
- 道具实例可使用 `width`、`height` 覆盖配置中的默认尺寸。
- 地形实例使用 `terrainType`：`ground` 为实体地面，`platform` 为单向平台。
- 编辑器和游戏分别通过表现字段解析模块解释同一套数据，避免玩法代码直接依赖编辑器实现。

## 保存规则

- “保存到游戏”会把当前关卡写入 `platform_dome/data/levels/<关卡 id>.json`。
- 写入前使用 contract 统一校验并补充当前 `schemaVersion`。
- 已有文件会先复制到本工程的 `.editor-backups/`，再写入新内容。
- 新增关卡会登记进 `platform_dome/data/levels/manifest.json`。
- 游戏启动时会读取该清单并加载其中列出的全部关卡。
- 保存失败时不会覆盖原文件；数据校验错误也会阻止保存。

## 关卡结构

- `spawnPoints`：命名出生点列表。
- `initialSpawnId`：新游戏或直接进入关卡时使用的出生点。
- `mechanisms`：统一保存特殊对象，通过 `type` 区分 `switch`、`gate`、`entrance`、`exit` 和后续类型。
- `story` 与 `quest` 不再写入关卡 JSON，后续由独立任务/剧情系统管理。
- 会话、任务、物品、动画演绎与角色使用独立的 `content.json`，不写入关卡文档。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `V` | 选择；拖动对象移动，拖动空白区域平移地图 |
| 中键拖动 | 平移地图 |
| `R` | 地形 |
| `A` / `I` | 角色 / 道具 |
| `M` | 机关、闸门、入口或出口 |
| `D` / `Delete` | 删除工具 / 删除选中对象 |
| 滚轮 | 以指针为中心缩放 |
| 方向键 | 按网格微调；`Shift` 为 10 像素 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+D` | 复制选中对象 |
| `Ctrl+S` | 保存到游戏 |
| `0` | 适应窗口 |

## 校验

```powershell
npm test
npm run check
```

`npm run check` 会检查 JavaScript 语法、关卡 JSON、角色与道具引用、闸门与机关引用、入口绑定出口以及关卡清单完整性。
