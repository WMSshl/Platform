# 关卡 JSON 格式

地图编辑器输出与游戏运行时读取的是同一份关卡数据。关卡只描述世界内容，不保存剧情或任务状态。

## 坐标规则

- 世界坐标原点位于地图左上角。
- 矩形对象和角色位置使用中心点坐标。
- 世界宽度和高度决定镜头边界。

## 世界与背景 `world`

```json
{
  "world": {
    "width": 2800,
    "height": 1400,
    "backgroundColor": "#0f172a",
    "background": {
      "type": "tiled",
      "id": "map/tiled/courtyard",
      "sourcePath": "assets/map/tiled/courtyard/source/map.json",
      "mapPath": "assets/map/tiled/courtyard/map.json",
      "fileName": "courtyard.json",
      "revision": "2026-10-21T08:00:00.000Z",
      "sourceWidth": 3200,
      "sourceHeight": 1600,
      "tileWidth": 32,
      "tileHeight": 32,
      "tilesets": [],
      "collisions": []
    }
  }
}
```

- `backgroundColor`：没有背景图时的底色。
- `background`：可选背景判别联合，`type` 为 `image` 或 `tiled`。
- 图片背景使用 `path`、`fit` 和 `revision`；Tiled 背景使用 `sourcePath`、`mapPath`、tileset 与碰撞。
- 两类背景都由世界边界驱动，不保存独立位置、缩放或旋转。
- `mapPath` 指向 Phaser 可读取的 Tiled JSON；`tilesets[].imagePath` 指向游戏项目内的图片。
- 碰撞只包含裁剪和合并后的矩形，`terrainType` 为 `ground` 或 `platform`。

## 出生点 `spawnPoints`

每张地图可以拥有多个具名出生点：

```json
{
  "spawnPoints": [
    {
      "id": "spawn-start",
      "name": "默认出生点",
      "x": 150,
      "y": 1220
    }
  ],
  "initialSpawnId": "spawn-start"
}
```

- `id`：稳定引用名，供后续任务、剧情和传送条件使用。
- `initialSpawnId`：新游戏或目标关没有指定入口时使用的出生点。
- 出生点与入口职责不同：出生点是通用落点，入口是出口切换地图时的目标落点。

## 地形 `solids`

- `id`：稳定唯一编号。
- `x`、`y`：矩形中心坐标。
- `width`、`height`：矩形宽高。
- `color`：占位颜色。
- `terrainType`：`ground` 或 `platform`，省略时按 `ground` 处理。

地面 `ground` 四周都有碰撞。平台 `platform` 只在角色从上方落下时
提供支撑；从下方跳跃、从侧面接触或角色主体已与平台重叠时都不会被
阻挡。角色站在平台上时按 `S` 或下方向键，会临时穿过当前平台下落。

## 角色 `actors`

- `instanceId`：关卡内唯一实例编号。
- `actorId`：引用 `actors.json`。
- `x`、`y`：放置位置。
- `scaleX`、`scaleY`：可选水平/垂直缩放倍率，默认 `1`。
- `scale`：可选的旧版统一缩放字段；未提供 `scaleX`、`scaleY` 时同时作用于两个方向。

角色属性保存在角色配置中，关卡只负责实例和位置。

## 道具 `items`

- `instanceId`：关卡内唯一实例编号。
- `itemId`：引用 `items.json`。
- `quantity`：拾取数量。
- `x`、`y`：放置位置。
- `width`、`height`：可选显示与碰撞尺寸；省略时读取道具配置中的默认尺寸。

## 机关与特殊对象 `mechanisms`

机关、闸门、入口和出口统一存放于 `mechanisms` 数组，通过 `type` 区分，便于继续扩展新类型。

公共字段：

- `id`：关卡内唯一编号。
- `type`：`switch`、`gate`、`entrance`、`exit` 或后续扩展类型。
- `x`、`y`：中心坐标。
- `width`、`height`：作用区域尺寸。
- `color`：编辑器占位颜色。

### 开关 `switch`

- `interactionRange`：玩家可交互距离。
- `targetGateId`：启动后打开的闸门 ID。
- `storyFlag`：可选剧情/任务标记。
- `prompt`：交互提示。

### 闸门 `gate`

带碰撞的静态区域，默认阻挡玩家；可被开关打开。

### 入口 `entrance`

- `activation`：固定为 `player-center-touch`。
- 角色中心接触入口矩形边缘时触发传送。
- `targetExitId`：传送目标出口的全局 ID。

### 出口 `exit`

出口是被动传送目标，不主动触发，也不保存关卡或通关条件。游戏根据目标出口所在的关卡自动确定切换目标；同一个出口只能被一个入口绑定。

## 关卡清单

`data/levels/manifest.json` 保存游戏启动时需要加载的关卡 ID。地图编辑器保存后会自动更新该清单。
