# 穹顶回响

这是一个基于原生 HTML、JavaScript ES Modules 和 Phaser.js 的横版剧情动作游戏原型。

## 职责
只负责消费 contract 数据，不实现编辑能力。
数据不合预期 → 抛 contract 校验错误，禁止在运行时做兜底兼容。
共享协议位于工作区的 `platform_contract/`，当前关卡 schema 版本为 `1`。
运行时只在 loading 阶段执行迁移和校验，玩法热路径不调用 contract。

## 性能（热路径红线）
每帧执行的代码中禁止：新对象分配、反射、用字符串拼接做 key。
资源与数据在 loading 阶段解析完毕，运行时只读。

## 扩展性
新玩法走 system/component 注册，禁止在主循环里加条件分支。

## 启动方式

项目不需要打包或编译，但浏览器出于安全限制，不能稳定地通过双击 `index.html` 加载 ES Modules。可以在工作区根目录执行：

```powershell
pnpm --filter platform-dome start
```

也可以在本项目目录执行：

```powershell
npm start
```

然后打开：

```text
http://127.0.0.1:8081
```

## 当前操作

- `A` / `D` 或左右方向键：移动
- `Shift`：加速跑，消耗耐力；空中只增加横向速度
- `Space` / `W` / 上方向键：跳跃
- `J` 或鼠标左键：近战攻击
- `K`：防御，消耗耐力
- `E`：启动机关
- `S` / 下方向键：从当前单向平台下落
- `Esc`：暂停

- 主菜单、开始新游戏、读取手动存档

- 镜头同时跟随玩家的水平和垂直移动

- 地面攻击期间锁定移动和跳跃；空中攻击保留横向速度
- 敌人巡逻、发现玩家、进入攻击距离、攻击前摇和范围伤害

## 当前限制

- 主角使用 `assets/player/` 中的像素精灵表，其他角色仍使用运行时占位图。
- NPC 已有统一角色定义结构，但完整对话系统尚未进入第一版。
- 当前只有一个手动存档位显示在界面上，底层存储接口已经支持多存档位。
- 地图使用矩形地形与数据驱动的机关对象；独立地图编辑器位于 `platform_editor`，可直接写入本项目关卡目录。
- 关卡数据由 `platform_contract` 统一定义和校验，编辑器保存时会写入当前 `schemaVersion`。
- 游戏会读取编辑器导入的 `world.backgroundAsset` 并预加载地图背景。
- 角色实例 `scaleX`、`scaleY` 会分别影响显示、物理体和血条；道具实例支持覆盖宽高。
- 地形支持 `ground` 实体地面和 `platform` 单向平台；平台仅从上方提供支撑，可从下方跳穿。
- 角色基础显示与物理体统一按 1.5 倍缩放，近战技能范围同步扩大 1.5 倍，跳跃最大高度调整为原来的 1.5 倍。
- 剧情与任务不再写入关卡 JSON，后续由独立任务/剧情系统管理。
